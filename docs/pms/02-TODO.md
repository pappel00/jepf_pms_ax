# PMS TO-DO 리스트

> 요구사항 문서(`01-요구사항-초안.md`)에서 논의 중 "후속"으로 미룬 항목을 모아 둔 목록입니다. 우선순위는 협의 후 정합니다.
> 상태: ☐ 미착수 / ◐ 일부(목업) / ☑ 완료 — 마지막 정리 2026-10-13

## 확정된 후속 과제 (사용자 요청)

- ◐ **직무·등급별 M/M 단가 관리 + 인건비 환산 → 프로젝트 예상 원가 연동** (목업 완료 2026-10-15: 단가표·인력 등급·투입 기준 인건비 환산, 요구사항 3.21 / 남은 것: RFP 확정 M/D 연동, 난이도 가중 결정, 제안서 이익률 연동, 실제 반영) (요청: 2026-10-13, 투입 관리 설계 시 결정)
  - 단가 관리(직무/등급별, 적용 기간) 메뉴
  - 투입 인력의 M/M × 단가 = 인건비 → 프로젝트 예상 원가·제안서 이익률과 연동
  - RFP 평가 확정 M/D(원가 산정용 확정 값) 단계와 함께 설계 (요구사항 문서 3.12 참고)
  - 난이도 가중치(하/중/상) 반영 여부 결정

## 영업단계

- ☐ RFP 평가 → 프로젝트 예상 원가 연동(확정 M/D 입력, 단가 환산) — 위 단가 관리와 묶음
- ☐ 수주 시 RFP 항목 → 요구사항 정의서 → WBS 자동 연결 고도화 (요구사항 ID 추적)
- ☐ 발주금액 부가세 포함 여부·통화·실패 사유 코드화(공통코드)
- ☐ RFP/제안서 실제 파일 저장(`module-file` 연동)

## 단계전환 / 수행 단계

- ☐ 수행단계전환: 소요일 산정을 투입 인원·일정 제약 기준으로 고도화
- ☐ 단계전환 승인 절차, 전환 취소(롤백)
- ☐ 투입 인력 변경 시 기존 WBS 담당자 재배정 제안 (미배정/제외 인력 업무)
- ☐ 필수 산출물 전부 등록 시 단계말 검토 업무 진척 자동 반영, 검토/승인 권한(PM·고객사 열람자)
- ☐ 진척 스냅샷(주간) 저장 → 보고서의 기간별 진척 증감, 번다운
- ☐ 보고서 작성·제출·확정 상태와 이력, 발주사 공유용 양식, 자동 알림(메신저)
- ☐ 이슈 1건 : 업무 N건 연결, 이슈 해결 시 업무 일정 조정 제안, 내 업무 대시보드에 담당 이슈 표시

## 메신저 연동 (v1 범위)

- ☐ 알림 채널 추상화(텔레그램 + Mattermost): 오늘 할 일 발송, 버튼으로 진척률 입력
- ☐ 협력사 인력: 내 업무 알림에서 진척·이슈 등록(관리자 대리 입력 포함)
- ☐ Mattermost 환경 확인(기존 서버 네트워크 경로, 봇 발급 권한, 사용자 매핑 키)

## 인력관리

- ☐ 월별 투입 계획(월별 투입률) 입력 — 현재는 M/M ÷ 기간으로 자동 환산
- ☐ 실적 M/M 월 마감 및 협력사 인력 실적 확인
- ☐ 프로젝트별 접근 권한(멤버 외 열람 제한), 프로젝트 관리자 변경 이력
- ☐ (제외 결정) 비투입 일정(휴가·교육·타 업무) — 필요해지면 재검토

## 운영 단계

- ☐ 운영 단계 메뉴 구현 — 제안 목록은 요구사항 문서 3.20 참고 (장애·문의 관리, 변경 요청, SLA 관리, 운영 보고 등)
- ☐ 운영 프로젝트 정보 변경 시 승인/이력 필요 여부 결정
- ☐ 운영 종료(계약 만료/갱신) 상태와 재계약 연계

## 기술 / 공통

- ☐ 목업 → 실제 백엔드(`module-pms`) 구현: ERD 설계(화면 확정 후), API, 권한(프로젝트 멤버 기반)
- ☐ 원본 폴더 OneDrive 파일 로컬 유지 설정 후 직접 빌드/실행(현재는 로컬 복사본에서 실행)
