## 2. 남은 작업 (우선순위 순)

- ☐ **DB 소유자 정리**(사용자 실행): 테이블 소유자가 `postgres`라 컬럼 추가가 막힌다 → postgres 계정으로 `00b_fix_table_ownership.sql` 실행(접속 DB는 `jepf`), 이어서 `05_alter_pms_money_bigint.sql` 적용
- ◐ **참여 프로젝트(◐)·본인 건(○) 판정**: 목록 조회 범위·멤버 외 열람 제한·진척 본인 입력은 완료(`ProjectAccess`) / 남은 것: RFP·제안서 조회 범위(평가자 기준), id 로 직접 조회하는 일부 API, 프로젝트 관리자 변경 이력
- ☐ **화면에서 권한 없는 버튼 숨기기**: 서버는 관리자 전용 쓰기를 막지만 화면은 버튼을 그대로 보여 주고 오류 메시지로 알린다(이슈·산출물·보고서·일정 조정 제안)
