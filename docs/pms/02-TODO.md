## 1. 남은 작업 로드맵 (제안 순서)

### A. 기반 정리 — 먼저
- ☐ **DB 소유자 정리**: 테이블 소유자가 `postgres`라 컬럼 추가가 막힌다(`00b_fix_table_ownership.sql`을 postgres로 실행). 이어서 `05_alter_pms_money_bigint.sql` 적용
- ☑ **화면의 현재 사용자(`ME`) → 로그인 사용자로 교체** (2026-10-28: `pmsStore.ME` 가 로그인 사용자 이름으로 갱신, 로그인·로그아웃 이벤트 `jepf-auth-changed` 반영)
- ◐ **참여 프로젝트(◐)·본인 건(○) 판정을 서버에 적용** (2026-10-28 `ProjectAccess`: 목록 조회 범위·멤버 외 열람 제한·진척 본인 입력) / 남은 것: RFP·제안서 조회 범위(평가자 기준), id 로 직접 조회하는 일부 API, 프로젝트 관리자 변경 이력
- ☑ **인력의 이슈·산출물 등록 차단(서버)** (2026-10-28: 프로젝트 관리자·ADMIN만 등록/수정, 위반 시 `ERR-PMS-0036`) — 화면은 아직 버튼을 숨기지 않고 서버 안내 메시지로 알린다
- ☐ 목업 기준일 `TODAY`(2026-10-13) 상수를 실제 날짜로 교체 — 샘플 데이터(WBS·이슈·보고서)가 10월 중순에 맞춰져 있어 교체 시 지연·계획 진척이 크게 달라진다. 샘플 데이터 날짜 이동과 함께 진행

### B. 기능 보완 — 서버 구현에서 남긴 것
- ☐ **WBS 생성을 서버로**: 지금은 단계전환 승인 직후 화면이 만든 WBS를 일괄 저장 → `selection_json`·RFP 서버 데이터로 서버가 생성
- ☐ **RFP 확정 M/D → 프로젝트 예상 원가 환산 연동** — 결정 필요: M/D→M/M 환산 기준, 적용 직무·등급
- ☐ **진척 스냅샷 자동 저장 스케줄러**(주 1회) — 계획 진척 계산의 기준일을 실제 날짜로 바꾼 뒤
- ☐ **실제 파일 저장**(`module-file` 연동): RFP 원문, 제안서 버전, 산출물 파일 (현재는 파일명·크기 표시값만)
- ☐ 평가자 추가 지정 UX: 목업의 「평가자로 보기」는 제거됨(본인 평가만) — 평가 관리자의 대리 입력이 필요한지 결정
- ☐ 실적 M/M 월 마감, 협력사 인력 실적 확인

### C. 메신저 연동 (v1 범위) — 사전 확인 후
- ☐ Mattermost 환경 확인(서버 네트워크 경로, 봇 발급 권한, 사용자 매핑 키), 텔레그램 봇
- ☐ 메신저 ERD 설계: 프로젝트별 채널 설정(`pms_notify_setting`)·알림 발송 이력(`pms_notify_log`)·콜백 토큰 (ERD 13절 3번)
- ☐ 알림 채널 추상화: 오늘 할 일 발송, 버튼으로 진척률 입력
- ☐ 협력사 인력: 내 업무 알림에서 진척·이슈 등록(관리자 대리 입력 포함)
- ☐ 보고서 제출·후속 조치·이슈 알림 연동

### D. 고도화
- ☐ 수주 시 RFP 항목 → 요구사항 정의서 → WBS 자동 연결 고도화(요구사항 ID 추적)
- ☐ 수행단계전환 소요일 산정을 투입 인원·일정 제약 기준으로 고도화
- ☐ 투입 인력 변경 시 기존 WBS 담당자 재배정 제안(미배정/제외 인력 업무)
- ☐ 필수 산출물 전부 등록 시 단계말 검토 업무 진척 자동 반영
- ☐ 번다운, 업무 단위 스냅샷, 발주사 공유용 보고서 양식
- ☐ 내 업무 대시보드에 담당 이슈 표시
- ☐ 투입 관리 히트맵에서 월 투입률 바로 수정
- ☐ 고객사 정보 변경 이력, 영업 활동 이력, 고객사별 프로젝트 이력 조회; 영업 노트 수정·삭제 권한·첨부
- ☐ 이관 이슈 승계, 이관 기회 수주 → 프로젝트 자동 생성, 운영 영업 → 수행 단계 기회 역조회, 기회 단위 첨부

### E. 운영 단계 후속
- ☐ 운영 종료(계약 만료/갱신) 상태와 재계약 연계
- ☐ 운영 프로젝트 정보 변경 시 승인/이력 필요 여부 결정
- ☐ 변경 요청·SLA 관리·운영 보고 등 운영 메뉴 확장 (요구사항 3.20 제안 목록)

### F. 품질·배포
- ☐ 서버 단위/통합 테스트 작성 (현재는 API·화면 수동 확인 중심)
- ☐ 개발용 시드 정리: `PmsDevDataSeeder`·`pms-seed-*.json`은 로컬 전용 — 운영 배포 시 제거
- ☐ 코드 리뷰(`/code-review`)·보안 리뷰, 커밋 단위 정리

### 제외 결정 (필요해지면 재검토)
